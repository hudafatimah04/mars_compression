# Mars Terrain Compression website

From this folder, run `npm ci` once. On Windows, double-click `start-website.bat` or run `npm.cmd run dev:watch`. Open [the local preview](http://127.0.0.1:5173/). Saved changes appear automatically.

Run `npm run build` to check TypeScript and generate the static website in `dist/`.

For a hosted teammate preview, point your hosting project at `website/`, use the Vite preset and `npm run build`, and serve `dist`. Restrict access before sharing the hosted URL.

The [project README](../README.md) links to experiment results and the shared protocol.
